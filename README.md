# Time To Live

How do living and artificial systems survive together under shared constraints? As intelligence becomes increasingly distributed across biological, human, and computational agents, the central question is no longer how these systems perform, but how they persist. Energy is the only universal currency they share, shaping what can adapt and survive. _Time To Live_ responds by inviting artists to build a shared commons in which living artworks operate under constrained energy conditions, developing their own forms of intelligence through the exchange of signals, feedback, and dependencies. The project reframes intelligence as a relational practice oriented toward collective survival, continuity, and care.

### Running this app

```bash
bun install      # install dependencies
bun dev          # start dev server at localhost:3000
bun run build    # export static site to out/
```

### Tech Stack

- [Next.js 15](https://nextjs.org) - React framework
- [TypeScript](https://www.typescriptlang.org) - Type safety
- [Tailwind CSS 4](https://tailwindcss.com) - Styling
- [Bun](https://bun.sh) - Package manager and runtime
